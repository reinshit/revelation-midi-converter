# Privacy

Last updated: September 5, 2026

Revelation MIDI Converter processes MIDI files locally in the user's browser.
The application has no backend and does not upload MIDI files, generated MML,
project files, preferences, or keymaps to a project-controlled server.

The application stores preferences, the latest project, and the latest keymap
in browser storage on the user's device. Users can remove this data with the
Clear local data action or by clearing site data in the browser.

The application is hosted by Vercel. Vercel may process standard request data
required to deliver static files, subject to Vercel's own privacy practices.

The application does not provide user accounts, advertising, analytics, or
payment processing.
